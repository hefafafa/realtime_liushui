# realtime_liushui · B站直播本场流水看板

一个 Tampermonkey（篡改猴）用户脚本：**只在 bilibili 直播间使用**，在直播间右上角浮出一个面板，
实时统计主播**本场**的付费礼物 / 超级留言(SC) / 大航海，并读取 B站官方**高能榜**贡献值。

- 数据只存在你自己浏览器的 localStorage 里，不上传任何服务器。
- 不加载远程代码、不申请额外权限、不插广告、不上报统计。
- 免费使用；打赏与功能完全无关（详见下方「打赏」）。

## 注意事项

由于是抓websocket，不会自动更新，用于监控整场直播，请手动点击重置！！！！！

## 能看什么

| 区域 | 说明 |
| --- | --- |
| 本场总计 | 礼物 + SC + 大航海（红包不计入，见下） |
| 抽成后流水 | 点一下把金额换成"扣完 B站平台计提、真正打进主播账户"的钱（官方口径：一般收益与大航海在 PC/安卓端按 **50%** 计提，税前） |
| 贡献榜 | 本场谁打了多少（来自弹幕协议：礼物 / SC / 大航海） |
| 高能榜 | B站官方贡献值排名（纯接口，与贡献榜互相印证），只露 3 行、可滚动 |
| 最近事件 | 逐条流水：礼物（含盲盒爆出物、连击）、SC、上舰（含打折舰长的实付修正） |
| 导出 CSV | 按用户贡献 + 汇总项（含抽成后金额） |
| 金额单位 | 1000 电池 = 1 元；面板右上角可切换人民币 ⇄ 日元 |
| 自检小窗 | 屏幕左上角，显示三条通道各自的收包数、未识别命令、疑点样本（排错用） |

## 安装（3 步）

1. 装 **Tampermonkey（篡改猴）**：
   - Edge：Edge 加载项里搜 `Tampermonkey`
   - Chrome：Chrome 应用商店里搜 `Tampermonkey`（商店打不开就换 Edge / Firefox）
2. 装本脚本：把 `realtime_liushui.user.js` **拖进浏览器窗口**，篡改猴会弹出安装页 → 点「安装」。
   - 被当成下载而不是安装时：打开篡改猴「实用工具 → 导入」，或地址栏输入 `file:///` + 文件完整路径回车。
   - 从 GitHub / GreasyFork / 脚本猫 等地址安装的话，直接点链接即可。
3. 打开任意直播间 `https://live.bilibili.com/房间号`。

> 微信/QQ 直接传 `.js` 常被拦，可以发 zip 压缩包，对方解压后再拖进浏览器。

## 使用方法

1. 打开直播间后，页面右上角会出现一个 **💰 圆钮**（默认收起状态）。
2. **点一下 💰** 展开面板；再点面板右上角 **✕** 收起。
3. 面板可以**拖动**：拖标题栏或 💰 都能移动，位置会被记住（贴边会自动吸附）。
4. **换房间**：面板底部有输入框，填房间号点「跳转」，或直接改地址栏访问另一个直播间。
5. **看抽成后的钱**：点总金额右侧的「抽成后流水」按钮切换；开启后礼物 / SC / 大航海三行也会同时显示扣成后金额，
   原面值以灰色小字附在旁边。
6. **导出**：点「导出 CSV」下载本场明细（按用户贡献 + 汇总项，含抽成后金额）。
7. **清零**：点「重置本场」（会二次确认）清空该房间所有统计。
8. **首次使用**会在面板里显示一次提示卡，点「知道了」后不再出现。
9. **遇到数字不对**：点面板左下 💰 上方的自检小窗 🡒 或在页脚点「复制诊断信息」，
   它会复制版本号、房间号、两条通道收包统计、未识别命令与最近事件；把这段一起发给作者，定位会快很多。

> 只有 `live.bilibili.com` 下的直播间页面会加载这个脚本；B站其它页面（首页、视频、个人空间等）不生效。

## 关于「红包」

按本站口径：**红包本身没有价值，只有内容物有价值** —— 所以红包报文只做登记、**一分钱都不计入流水**；
内容物被中奖人真正用掉、以普通礼物形式发出来时，才按礼物流水记。
（B站官方口径是红包金额的 20% 投喂给主播，脚本里保留了这个参考值，只用于对账。）

## 已知限制

- **超大直播间可能小幅漏记**：B站对匿名连接有流过滤。脚本用两条通道互补 + 配对去重降低漏账概率，但不保证 100%。
- **看不出投喂来自哪个端**：所以 iOS 的低比例（一般收益先扣 30% 渠道费）算不出来，「抽成后流水」统一按 PC/安卓的 50% 折算。
- **金额是税前**：个税、提现手续费不在本看板范围内。
- 数据按房间分开，各自保留 24 小时。
